## 🚀 Installation & Quick Start

### Method 1: Automatic via WordPress Admin (Recommended)
1. In your WordPress admin dashboard, navigate to **Plugins → Add New**.
2. Search for **"Nexura AI Search Optimizer"**.
3. Click **Install Now**, then click **Activate**.
4. Follow the 60-second Setup Wizard to generate your `/llms.txt` and configure AI crawler permissions.

### Method 2: Manual Upload via ZIP
1. Download the latest release from [GitHub Releases](https://github.com/nexurasecurity/nexura-ai-search-optimizer/releases) or [WordPress.org](https://wordpress.org/plugins/nexura-ai-search-optimizer/).

3. Select the downloaded `.zip` file and click **Install Now**.
4. Activate the plugin.

### Method 3: Via WP-CLI
```bash
wp plugin install nexura-ai-search-optimizer --activate
```

## ❓ Frequently Asked Questions (FAQ)

### What is Generative Engine Optimization (GEO)?
Generative Engine Optimization (GEO) is the practice of structuring and optimizing website content so that AI search engines (like ChatGPT Search, Perplexity AI, Claude, and Google AI Overviews) can easily understand, retrieve, and cite your pages when answering conversational queries.

### What is `/llms.txt` and why do I need it?
`/llms.txt` is an emerging community standard (similar to `robots.txt` and `sitemap.xml`) specifically designed for Large Language Models. It provides a curated index of your site's most important content in clean Markdown, helping AI models discover your best resources without wasting context window tokens on unnecessary HTML markup.

### Will this plugin slow down my WordPress site?
Not at all. Nexura is engineered strictly according to WordPress Core coding standards. It runs lightweight rewrite rules, caches output with native WordPress transients, and executes zero external API calls for core features.

### Does this replace my existing SEO plugin?
No. Nexura works seamlessly alongside Yoast SEO, Rank Math, All in One SEO, and SEOPress. Your existing SEO plugin optimizes for Google search algorithms, while Nexura optimizes for AI search and generative discovery.
